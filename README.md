# GISFishIt v3

Web Helper untuk membantu nelayan Indonesia menangkap ikan secara aman, legal, dan berkelanjutan — dikembangkan oleh mahasiswa Sistem Informasi Kelautan, UPI Kampus Serang.

## Fitur Utama
- **Desain Maritim Indonesia**: Palet warna pasir, kayu jati, laut dalam, dan terumbu karang (`Manrope` + `Inter` + `JetBrains Mono`) dengan mode gelap otomatis (18:00–05:59) atau manual.
- **Peta Zona Tangkap (2GB RAM Friendly)**: Leaflet `preferCanvas: true` + MarkerCluster, zona konservasi KKP/BIG (biru), 64 zona simulasi edukasi berlabel `(SIMULASI)`, filter klaster tanpa reset state, favorit per marker (`★`), rute garis lurus (jarak, bearing, estimasi waktu & BBM), serta impor GeoJSON.
- **Cuaca Laut Real-Time**: Open-Meteo Marine & Weather API (tanpa API key) dengan cache 1 jam, Sunrise/Sunset harian, fase bulan 8 varian SVG, grafik 24 jam Chart.js (lazy-load), skeleton shimmer, dan widget cuaca mini di Beranda.
- **Keselamatan Pelayaran**: Tombol SOS dengan modal konfirmasi hitung mundur 3-2-1 + fallback SMS/Telepon, multi-kontak darurat di Pengaturan, pelacakan GPS Breadcrumb (viewer peta + ekspor GPX + hapus jejak), serta Catch Log (timeline viewer + statistik + filter + ekspor CSV).
- **Komunitas & Multi-Bahasa**: Laporan tangkapan via modal kustom (mode tekan `R`), sinkronisasi opsional Supabase, serta 6 bahasa lengkap (`en`, `id`, `fr`, `jp`, `es`, `ar` dengan dukungan RTL).
- **PWA Offline-First**: Precaching relatif dengan Workbox 7.3, indikator offline otomatis, dan notifikasi cuaca berbahaya.

## Setup Data Resmi KKP/BIG
Unduh GeoJSON kawasan konservasi ke `data/kkp-zones.geojson`:
```
https://kspservices.big.go.id/satupeta/rest/services/PUBLIK/SUMBER_DAYA_ALAM_DAN_LINGKUNGAN/MapServer/35/query?where=1%3D1&outFields=*&outSR=4326&f=geojson
```

## Setup Supabase (Opsional)
```sql
create table reports (
  id bigint generated by default as identity primary key,
  lat double precision not null,
  lng double precision not null,
  species text,
  weight_kg numeric,
  note text,
  created_at timestamptz default now()
);
alter table reports enable row level security;
create policy "read" on reports for select using (true);
create policy "insert" on reports for insert with check (true);
```
